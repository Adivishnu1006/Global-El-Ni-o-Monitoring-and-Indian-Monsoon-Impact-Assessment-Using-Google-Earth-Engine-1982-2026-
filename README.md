# Global-El-Ni-o-Monitoring-and-Indian-Monsoon-Impact-Assessment-Using-Google-Earth-Engine-1982-2026-
A Google Earth Engine project analyzing the relationship between ENSO (El Niño–Southern Oscillation) and Indian monsoon variability using NOAA OISST, CHIRPS rainfall, and MODIS NDVI datasets from 1982–2026.
