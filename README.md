# Global El Niño Monitoring and Indian Monsoon Impact Assessment (1982–2026)

This project investigates how El Niño events influence Indian monsoon rainfall and vegetation dynamics using satellite observations and climate datasets processed in Google Earth Engine (GEE).

The workflow combines Pacific Ocean sea surface temperature (SST) analysis, ENSO event detection, rainfall assessment, vegetation monitoring, and near-real-time climate monitoring to understand the connection between global climate processes and environmental conditions across India.

## Key Highlights

* Analyzed 44 years of ENSO observations (1982–2025)
* Built a custom ENSO Event Catalog
* Identified major El Niño events including 1982, 1997, 2015, and 2023
* Assessed Indian monsoon rainfall response using CHIRPS precipitation data
* Evaluated vegetation response using MODIS NDVI
* Developed a 2026 Monsoon Monitoring Dashboard
* Generated raster datasets, charts, and climate impact maps

## Key Findings

* Strong El Niño years were associated with an average monsoon rainfall reduction of approximately 95 mm (-10.5%)
* The strongest event in the study period was observed in 2015 with a Niño 3.4 Index of 2.97°C
* Current 2026 Niño 3.4 conditions reached approximately +1.65°C, indicating Strong El Niño conditions
* Vegetation response varied regionally, highlighting the influence of irrigation and local environmental factors

## Datasets

* NOAA OISST V2.1
* CHIRPS Daily Precipitation
* MODIS MOD13Q1 NDVI
* FAO GAUL Administrative Boundaries
